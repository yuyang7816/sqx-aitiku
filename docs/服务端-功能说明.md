# 服务端功能说明

服务端没有给学生点的页面。它是一直开着的程序：用户端和管理端把「登录、刷题、交卷、错题本、AI 答疑、拍照搜题、会员支付」这些请求发给它，它检查是否允许、把结果存进数据库，必要时再去问微信、支付宝、短信、大模型、OCR 这些外面的服务。

可以把它理解成总台。两个前台（用户端、管理端）说的话，都由总台记账，并在需要时给外面的公司打电话。

数据库脚本在 `tiku_server/db/aitk.sql`。开发库名是 `aitk`。题目、章节、练习记录、错题本、会员订单、系统配置都记在这里。

启动类是 `com.sqx.SqxApplication`。端口是 **9165**，所有接口都在 `/sqx_fast` 下面。接口列表在：

http://127.0.0.1:9165/sqx_fast/doc.html

Redis 用于登录态、系统配置缓存等，启动前需要先开 Redis。

下面先说它为两个前台做哪些事，再说 AI / OCR 相关规则，最后说它会主动连接哪些外面的服务。

## 它为学生（用户端）做的事

这些都是用户在手机里点一下之后，由服务端完成的：

- **注册和登录**：检查手机号和短信验证码，或检查密码 / 微信授权。通过后发给用户登录凭证（JWT）。之后需要登录的请求都要带这张凭证，否则视为没登录。
- **学习计划**：保存学段、年级、教材版本、科目；只有计划完成后，用户端才会进入首页。
- **首页数据**：返回快捷入口、练习入口、今日学情摘要、推荐练习等。
- **题库与练习**：章节树、知识点、题集 / 试卷、题目列表与详情；提交答案、保存进度、练习记录。
- **错题本**：错题入库、掌握 / 待复习状态、批量删除、与云端同步。
- **收藏与搜题记录**：收藏题目、搜索 / 拍照搜题记录。
- **AI 答疑**：接收题目上下文与用户追问，调用配置好的大模型返回讲解。
- **拍照搜题（OCR）**：接收图片，识别文字并在题库中检索相似题。
- **学情分析**：聚合做题数据，返回正确率、薄弱点、学习报告、学习日历等。
- **会员与支付**：会员套餐、下单、微信 / 支付宝支付回调后改订单与权益。
- **推广与提现**：邀请关系、佣金、提现申请。
- **消息 / 在线客服**：站内消息与客服聊天记录保存在自己的库里。
- **文件上传**：头像、搜题图片等，可存本机目录或对象存储。

## 它为管理端做的事

- 工作人员登录（账号 + 密码 + 图片验证码）。
- 运营看板：用户、题目、练习等概况数字。
- C 端用户、账号注销申请、勋章定义。
- 章节题库、题目、题集维护。
- 首页快捷入口、练习入口、消息、用户反馈。
- 学情统计、用户错题本查看。
- 会员套餐与权益、提现审核。
- 在线客服会话处理。
- 系统配置：基础域名、登录认证、支付、短信、文件存储、客服、协议、OCR、AI、推广佣金、提现规则、字典等。
- 管理员、角色、菜单、操作日志。

## AI 答疑业务规则（代码核实）

用户端入口主要是「AI 学习 → AI 答疑」，以及错题本 / 搜题结果里的「AI 讲解」「继续追问」。

1. **总开关与平台**：管理端「系统配置 → AI 配置」中选择平台（如豆包等）并填写 API Key、模型名、接口地址。
2. **密钥位置**：写在 `sys_config` 表，由服务端读取；用户端页面上改文字不会变成已经开通。
3. **每日次数**：可配置每日免费次数；会员权益可提高或放开次数。次数用尽时用户端会提示。
4. **敏感词**：可配置敏感词，命中后拒绝或降级处理。
5. **未配 Key**：AI 功能不可用，但不影响普通刷题、错题本浏览。

## OCR 拍照搜题业务规则（代码核实）

1. **平台**：管理端「系统配置 → OCR 配置」选择识别平台（如本地侧车、百度等）并填写对应密钥。
2. **流程**：用户端上传题目图片 → 服务端识别文字 → 在题库中检索相似题 → 返回结果页，可继续 AI 追问。
3. **每日次数**：可配置 OCR 每日次数；会员权益可提高或放开。
4. **未配 Key / 服务不可用**：拍照搜题失败，不影响手动找题与章节练习。

## 对接了哪些外面的服务

下面每一项都是服务端真的会向外发送请求的。密钥没填时，它不会假装成功，用户端会看到失败提示。

### 短信

注册、验证码登录、找回密码等由服务端发短信。工程支持模拟发送、短信宝、阿里云、腾讯云等，具体走哪一家以管理端「短信通道」配置为准。

开发环境 `application-dev.yml` 里 `sqx.sms.mock: true` 时，不发真实短信，验证码固定为 `123456`。

- 腾讯云短信：https://cloud.tencent.com/product/sms
- 阿里云短信：https://www.aliyun.com/product/sms

### 微信登录

用户选择微信登录时，服务端用小程序 / 公众号 / App 的 AppId 与 Secret 换取用户标识。密钥在管理端「登录认证」中配置。没配好时，用户端会提示微信登录暂未开通。

微信公众平台：https://mp.weixin.qq.com/

### 微信支付 / 支付宝

用户开通会员时，服务端向微信或支付宝下单，并把拉起支付需要的信息交回手机。支付完成后，对方访问服务端的通知地址，服务端核对之后，再把订单改成已支付、发放会员权益。

- 微信支付商户平台：https://pay.weixin.qq.com/
- 支付宝开放平台：https://open.alipay.com/

### 图片存储

上传接口按配置走 **本机磁盘目录** 或 **阿里云 OSS**。OSS 未配好时，可先用本地上传路径联调。阿里云 OSS：https://www.aliyun.com/product/oss

### 大模型（AI 答疑）

AI 答疑会请求已配置的大模型接口（如豆包）。密钥在管理端「AI 配置」维护。未配 Key 时 AI 功能不可用，不影响普通刷题。

### OCR 识图

拍照搜题会请求已配置的 OCR 能力。密钥在管理端「OCR 配置」维护。

## 这些不是外面的公司

- **错题本、收藏、练习进度、学情统计**：只改自己数据库里的数据。
- **学习计划、勋章、站内消息**：自己的服务器处理。
- **推广佣金记账、提现申请**：系统只记录申请与审核结果；真正打款仍需人工按用户填写的收款信息处理。
- **在线客服消息**：自己的服务器保存与转发。
- **操作日志、权限、角色**：只约束管理端工作人员。

## 两个前台怎样和它配合

用户端和管理端都不直接「自己改数据库里的题目和订单」。它们把请求发给服务端，服务端再决定要不要去问微信、短信、图床或大模型。

所以：

- 服务端没启动时，两个网站都能打开界面，但登录、列表、刷题、AI、支付都会失败。
- 外面的密钥只配在服务端能读到的配置（管理端「系统配置」写入库表，或环境相关 yml）里。只在用户端页面上改文字，不会变成已经开通了微信支付或 AI。
- 管理端改完题目、章节、AI / OCR 配置并保存后，用户端下次请求才会用到新内容。
