# 管理端功能说明

管理端是给平台工作人员用的网站，在电脑浏览器里打开。学生不使用这个网站。它用来管题库和用户、配置 AI / OCR、处理会员与提现，以及填写微信、支付、短信、图片存储这些外面服务的账号。

程序里的名称是「AI题库管理后台」。工作人员登录后，左侧是菜单。能看到哪些菜单，由账号权限决定。没有权限的菜单不会出现。

下面的页面名称以当前后台侧栏为准。如果你后来在「菜单管理」里改过名字，以你屏幕上看到的为准。

## 登录

登录页要填账号、密码，还要看一张图片验证码。看不清就点图片换一张。验证码由服务端生成。服务端没启动时，图片是裂的，登录也会失败。

开源包 SQL 已带演示管理员，可用：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |

## 登录之后：运营看板

首页会展示运营概况，例如用户、题目、练习相关数字。数字来自自己的数据库。

## C 端用户

### C端用户

查看注册学生账号。可进入详情查看资料、学习计划、会员、钱包等相关信息。删除等敏感操作以实际按钮与权限为准。

### 账号注销管理

处理用户发起的账号注销申请。

### 勋章定义

维护用户端「勋章墙」里的勋章规则与展示信息。

## 在线客服

查看并回复用户从用户端「在线客服」发来的会话消息。这是站内客服，不是手机短信。

## 首页配置

### 首页快捷入口

维护用户端首页那一排彩色图标入口（如刷题中心、拍照搜题、试卷中心等）。改完保存后，用户端下次打开首页才会看到新入口。

### 练习入口

维护「刷题中心」页上的练习入口卡片（如章节练习、知识点练习、专项训练、真题模拟等）。

## 题库管理

### 章节题库

维护学科章节树。用户端「章节练习」读的就是这里的结构。

### 题目管理

新增、编辑、上下架题目；可维护题干、选项、答案、解析、讲解视频等。改完后用户端练习与搜题才会用到新内容。

### 题集管理

维护试卷 / 题集，供「试卷中心」「真题模拟」等入口使用。

### 年级学科

维护学段、年级、教材版本、科目等选项。用户端「学习计划」页面的下拉选项来自这里。

## 会员中心

### 会员套餐

配置用户端可购买的 VIP 套餐（价格、时长等）。

### 会员权益

配置会员能享受的权益说明，例如 AI 答疑次数、OCR 拍照搜题次数等。用户端会员中心会展示这些权益。

## 财务钱包

### 提现审核

审核推广用户发起的提现申请。点通过表示平台同意打款；系统不会自动调用微信企业付款或支付宝转账把钱转走，打款仍要按用户留下的收款账号人工处理。

## 用户学情

### 学情统计

查看整体或用户维度的练习与学情数据，便于运营分析。

### 用户错题本

查看某个用户云端错题本内容，便于客服排障或教研分析。

## 消息与反馈

### 消息管理

给用户发站内消息。这不是手机短信。

### 用户反馈管理

查看用户在「帮助与反馈」里提交的内容。

## 系统配置

这是最重要的配置中心。外面服务的账号大多填在这里。常见页签包括：

| 页签 | 用来做什么 |
|---|---|
| 基础配置 | 域名等基础项 |
| 登录认证 | 微信小程序 / 公众号等登录参数 |
| 支付配置 | 微信 / 支付宝商户参数 |
| 短信通道 / 短信模板 | 发验证码用哪家通道、模板内容 |
| 文件存储 | 本地目录或阿里云 OSS |
| 客服配置 | 在线客服 / 微信客服展示方式 |
| 协议 CMS | 用户协议、隐私政策、关于我们等文案 |
| OCR 配置 | 拍照搜题识别平台与密钥、每日次数 |
| AI 配置 | AI 答疑平台、API Key、模型、每日次数 |
| 推广佣金 / 提现配置 | 邀请奖励与提现规则 |
| 系统字典 | 通用字典项 |

改完要保存。用户端下次请求才会用新的密钥或文案。

## 系统管理

### 管理员管理 / 角色管理 / 菜单管理

决定谁能进后台、能点哪些页。

### 操作日志

查看工作人员在后台做过的重要操作，便于追责与排障。

## 和用户端怎么配合

管理端不自己保存学生的练习结果。它把操作发给服务端，服务端再写入数据库。所以：

- 服务端没启动时，验证码出不来，登录会失败。
- 在这里改完题目、章节、AI / OCR 配置并保存后，用户端下次打开才会看到。
- 外面的密钥只配在「系统配置」（或服务端环境相关配置）里。用户端没有地方填写微信支付商户号或大模型 Key。
