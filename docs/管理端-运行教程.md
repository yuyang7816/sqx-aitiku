# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `tiku_admin` 文件夹。程序名称是「AI题库管理后台」。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经出现「AI题库项目启动成功」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

## 开始之前要准备什么

安装 **Node.js 18 或更高**（建议 18 / 20 LTS）：https://nodejs.org/

`package.json` 要求 `"node": ">=18.0.0"`。

安装时勾选添加到 PATH。安装完成后，重新打开终端，输入：

```bash
node -v
npm -v
```

应看到 `v18.x` 或 `v20.x`，以及可用的 npm。

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

管理端通过环境变量 `VITE_API_BASE_URL` 决定请求发到哪里。

仓库里的 `.env.development` 可能默认指向线上演示地址。本地联调时，请在 `tiku_admin` 目录新建（或修改）`.env.development.local`，内容示例：

```env
VITE_API_BASE_URL=/sqx_fast/
```

或：

```env
VITE_API_BASE_URL=http://127.0.0.1:9165/sqx_fast/
```

说明：

- 写成 `/sqx_fast/` 时，浏览器先访问本机 Vite，再由 `vite.config.js` 代理到 `http://127.0.0.1:9165`
- 写成完整 `http://127.0.0.1:9165/sqx_fast/` 时，浏览器直接请求本机服务端
- 改完环境变量后，如果网站已经在运行，要先停掉再启动，修改才会生效

服务端端口必须是 **9165**，路径必须带 **`/sqx_fast`**。

## 第 2 步：安装依赖

在 `tiku_admin` 文件夹里打开终端，执行：

```bash
npm install
```

第一次可能要几分钟到十几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还是在 `tiku_admin` 文件夹里执行：

```bash
npm run dev
```

窗口里会出现本地地址。默认端口是 **5173**。没有自动打开时，手动打开：

http://localhost:5173

登录页上应能看到一张验证码图片。看不清就点图片换一张。验证码来自本机服务端。图片是裂的，说明第 1 步的地址不对，或服务端没有启动。

这个终端窗口也要一直开着。

## 怎样算成功

使用数据库里的管理员登录（见 [服务端运行教程](服务端-运行教程.md)）：

| 项目 | 值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `123456` |
| 验证码 | 登录页图片上的字符 |

登录成功后进入「运营看板」。左侧应能看到菜单，例如：

- 运营看板、C端用户
- 首页快捷入口、练习入口
- 章节题库、题目管理、题集管理、年级学科
- 会员套餐、会员权益、提现审核
- 学情统计、用户错题本
- 系统配置、管理员管理等

开源 SQL 已带菜单与管理员数据。若你自己清空了权限表，侧栏可能变空，需要重新导入或在「菜单管理 / 角色管理」中恢复。

题目列表里有演示题不代表后台「连错了」；库本来就有演示题库。要试用 AI / OCR，还需在「系统配置」填写对应密钥。

## 常见问题

**`npm` 不是内部或外部命令**  
Node.js 没装好，或安装后没有重新打开终端。

**`npm ERR!` 或引擎版本不符合**  
`node -v` 过低。安装 Node 18+ 后再执行 `npm install`。

**浏览器打不开 localhost:5173**  
看 `npm run dev` 的窗口是否还在。窗口里如果写的是别的端口，用窗口里打印的那个地址。

**验证码不显示，或登录提示网络错误**  
服务端没启动，或 `VITE_API_BASE_URL` 不是你的本机服务端。按键盘 `F12`，点「网络」或 Network，再点一次登录。请求应走到 `127.0.0.1:9165`（或你改过的地址），不应误发到错误域名。改完环境变量后，在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`。

**`Port 5173 is in use`**  
5173 已被占用。关掉之前的管理端窗口再启动。

**登录提示验证码不正确**  
图片上的字要和输入完全一致。点图片换一张再试。服务端窗口如果已经关掉，验证码对了也登不进去。

**能登录但左侧几乎没有菜单**  
检查当前账号角色权限，或重新导入 `tiku_server/db/aitk.sql` 后的菜单 / 角色数据。

**改了系统配置，用户端没变化**  
确认已经点保存；用户端需要重新打开页面或重新请求接口。服务端窗口必须还在运行。
