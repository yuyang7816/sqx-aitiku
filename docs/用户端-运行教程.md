# 用户端运行教程

按顺序做。这是给学生用的手机 / 网页应用，窗口标题是「AI题库」。推荐用 HBuilderX 打开 `tiku_uniapp` 文件夹来运行；也可以用命令行跑 H5。

先按 [服务端运行教程](服务端-运行教程.md) 导入 `tiku_server/db/aitk.sql` 并启动服务端。首页、刷题、错题本、AI 的数据都来自这个服务。服务端没启动时，页面也许能打开，但登录会失败，列表也可能是空的。

开源 SQL 已带演示题库。C 端用户需要自己注册，或使用你在演示环境准备好的账号。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。解压或安装后，打开软件，窗口标题是 HBuilderX，就说明安装成功。

如果要用命令行启动 H5，还需要安装 **Node.js 18+**，并在 `tiku_uniapp` 目录执行一次 `npm install`。

只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开 `tiku_uniapp/common/config.js`。仓库默认可能是线上演示地址：

```javascript
const ROOTPATH = "https://tiku.xianmaxiong.com/sqx_fast";
const ROOTPATH3 = "wss://tiku.xianmaxiong.com/sqx_fast/";
```

本地联调请改成你的本机服务端，例如：

```javascript
const ROOTPATH = "http://127.0.0.1:9165/sqx_fast";
const ROOTPATH3 = "ws://127.0.0.1:9165/sqx_fast/";
```

请确认端口与服务端 `application.yml` 的 **9165** 一致，路径带 **`/sqx_fast`**。

真机调试时，把 `127.0.0.1` 换成你电脑的局域网 IP（例如 `192.168.0.109`），并保证手机和电脑在同一网段。

改完后要重新运行一次，修改才会生效。

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。
3. 选中 `tiku_uniapp` 这个文件夹。不要选它的上一级（那一层还有 `tiku_server` 和 `tiku_admin`），也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`pages.json`、`manifest.json`、`common`、`package` 等。

## 第 3 步：在电脑浏览器里运行

### 方式 A：HBuilderX（推荐）

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。
3. 地址以控制台里打印的为准。
4. 打开后顶部标题是「AI题库」，底部应能看到 **首页、刷题、AI学习、错题、我的**。

HBuilderX 不要关。关掉后页面会打不开。

### 方式 B：命令行 H5

在 `tiku_uniapp` 文件夹执行：

```bash
npm install
npm run dev:h5
```

按终端提示打开本地地址（常见端口 **5174**）。

如果提示缺少 `cross-env`，先执行：

```bash
npm install cross-env -D
```

然后再运行 `npm run dev:h5`。

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里 `mp-weixin` → `appid` 若仍是原项目号码，你不是该小程序的开发成员时，微信会提示 AppID 没有权限。自己练习时，把这个 `appid` 改成你自己的小程序 AppID，或继续只用浏览器运行。

微信开发者工具里如果提示域名不合法，本地调试可以勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

## 怎样算成功

1. 能打开登录页。
2. 底部五个按钮（登录后）能点：**首页、刷题、AI学习、错题、我的**。
3. 按键盘 `F12`，点「网络」或 Network，再刷新。列表里的请求地址应是你在第 1 步配置的本机地址。仍出现非本机地址，说明第 1 步没有保存，或改完后没有重新运行。

### 本地如何登录

开发环境服务端默认开启短信模拟时：

1. 打开「验证码登录」或「账号密码登录」。
2. 若走验证码：手机号任意符合格式，验证码填 **`123456`**。
3. 若走账号密码：需要先注册，或使用你已准备好的账号。
4. 登录前勾选用户协议。
5. 第一次登录通常会进入「学习计划」页，选好年级、教材、科目后再进首页。

如果不想本地跑服务端，也可以先体验线上：

## 常见问题

**运行菜单是灰的，或提示没有浏览器**  
先安装 Chrome 或 Edge，再重启 HBuilderX。项目必须用「打开目录」打开 `tiku_uniapp`。

**一直停在「正在编译」，或浏览器是白屏**  
等控制台不再滚动。若出现红色报错，把第一行红色文字保留下来。常见原因是打开的文件夹不是 `tiku_uniapp`，或编译器还没下完。

**首页能开，但登录失败 / 接口报错**  
服务端没有启动，或 `tiku_uniapp/common/config.js` 仍是错误地址 / 错误端口。先看服务端窗口是否还有「AI题库项目启动成功」，再改第 1 步为 **9165**，然后重新运行。

**登录后一直停在学习计划页**  
这是正常流程。至少选一门科目并保存后，才会进入首页。

**收不到短信验证码**  
本地开发默认是模拟短信，请填 `123456`。正式环境需要管理端配置真实短信通道。

**微信开发者工具提示 AppID 无效或没有权限**  
换成你自己的小程序 AppID，或改用浏览器运行。

**真机预览接口失败**  
不要用 `127.0.0.1`（那是手机自己）。改成电脑局域网 IP，并检查电脑防火墙是否放行 9165 端口。

**AI / 拍照搜题一直提示不可用**  
检查管理端「系统配置」里的 AI 配置、OCR 配置是否已填写并保存，以及服务端能否访问对应厂商接口。普通刷题不受影响。
